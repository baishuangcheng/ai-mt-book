2 数据准备与语料构建

平行语料是机器翻译系统的核心，我们先从这一概念理解开始。

2.1 平行语料定义¶

平行语料是指：

同一语义内容在不同语言中的对应表达，或是同一语义在不同文字或相同语言的不同书写体系里的不同表示。下面案例中任何两列就是一堆平行语料，例如，简体汉文和英文对就是汉英对齐语料。简体汉文与传统蒙古文对就是汉蒙对齐语料。

📌 示例¶

本案例从语系、语言和文字三个层面系统展示了多语言差异：不同语系之间存在结构性差异，同一语系语言之间存在表达差异，而同一语言在不同书写体系下则体现为符号差异。这种多层差异共同构成了机器翻译与跨语言建模的核心挑战。

💡 提示：不同颜色表示语义对应关系：

  • 红色：主语（S）

  • 橙色：时间（Time）

  • 蓝色：地点（Location）

  • 紫色：宾语（Object）

  • 绿色：动词（Verb）

观察可以发现：

  1. 汉语与英语等语言多为 SVO 结构（也就是主谓宾结构，动词居中）。

  2. 蒙古语与满语为典型 SOV 结构（也就是主宾动结构，动词后置）。

  3. 简体与繁体属于同一语言的不同书写体系。可与蒙古语的不同书写体系比较，其类似与传统蒙古文与托忒式蒙古文，而蒙古文的其他书写体系完整迥异。

  4. 蒙古语存在多种书写系统（传统、托忒、西里尔、拉丁）

  5. 满文与蒙古文在结构上相似，但文字系统不同

👉 本例同时展示了： 语系差异 + 语言差异 + 文字差异

👉 可以理解为： 同一语义的“多语言对齐数据”

💡 提示 平行语料越多 → 翻译模型越好 数据质量比数量更重要¶

2.2 汉英语料¶

来源：

  • 新闻

  • 开源语料库

特点：

  • 数据规模大

  • 结构规范

2.3 汉蒙语料（关键）¶

来源：

  • 政府网站

  • 新闻媒体

  • 人工构建

特点：

  • 数据规模小

  • 质量不稳定

👉 教学重点：

让学生参与语料构建

2.4 数据格式¶


src.txt

tgt.txt

2.5 数据加载¶

def load_parallel(src_path, tgt_path):

	with open(src_path, encoding='utf-8') as f:

	 src = f.readlines()

	 with open(tgt_path, encoding='utf-8') as f:

		tgt = f.readlines()

		return [{"translation": {"src": s.strip(), "tgt": t.strip()}} 

	          for s, t in zip(src, tgt)]
