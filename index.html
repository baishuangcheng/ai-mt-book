人工智能交叉学科实践案例精析

一、教材定位¶

本教材面向人工智能交叉学科教学，强调：

  • 实践驱动（做中学）

  • 系统构建（从数据到应用）

  • 多学科融合（物理、化学、地理、语言、文化、古籍等）

本书采用“案例驱动”的方式，引导读者通过真实问题掌握人工智能技术，秉承先实践，后扣理论的思路。

二、本书核心思想¶

本教材围绕一个核心理念展开：

人工智能系统 = 数据 + 模型 + 任务设计

💡 提示

很多初学者会误以为“人工智能 = 模型”，也有人认为“人工智能=深度神经网络”，也有人认为“人工智能=大语言模型”。
实际上：

  • 没有数据 → 模型无法学习

  • 没有任务设计 → 模型无法应用

三、本书技术路线¶

本教材采用统一的实践路径：

问题定义 → 数据准备 → 模型构建 → 实验分析 → 系统扩展

💡 提示

这一流程适用于：

机器翻译 图像识别 文本分析 多模态任务

👉 是通用AI工程流程

四、本书结构¶

本书以案例为单位组织内容，每个案例包含：

问题分析 数据构建 模型训练 实验与对比 错误分析 系统扩展 实践任务

💡 提示

请重点关注：

👉 错误分析部分

这是理解模型本质最关键的部分。

六、学习方式建议¶

为了更好地掌握本教材内容，建议采用以下方式学习：

1️⃣ 动手优先 先运行代码 再理解原理 2️⃣ 多做对比

例如：

汉英 vs 汉蒙 直接翻译 vs 串接翻译 3️⃣ 关注错误 错误比正确更重要 错误体现模型能力边界

💡 提示

如果模型结果“看起来正确”，也要问：

为什么它是对的？

七、开源与协作学习¶

本教材支持开放式学习模式：

数据共建（学生提交语料） 模型优化（提交改进版本） 错误分析（案例积累）

💡 提示

你不仅是学习者，也可以是：

👉 数据贡献者 👉 模型设计者 👉 系统构建者

八、实验环境说明¶

推荐环境：

pip install -r requirements.txt

推荐工具：

Python VS Code Jupyter Book

九、本书目标¶

本教材的最终目标是：

让读者具备构建完整人工智能系统的能力

包括：

数据处理能力 模型训练能力 系统设计能力 十、拓展思考

在学习本书之前，可以思考：

为什么低资源语言难以处理？ 机器翻译是否真正“理解语言”？ 数据和模型哪个更重要？ 如何构建一个完整AI系统？

💡 最终提示

请始终记住：

人工智能不是“黑箱”，而是“可设计的系统”

本教材面向人工智能交叉学科实践教学，强调：

  • 可运行

  • 可扩展

  • 可协作

  • 可互动

所有案例均采用：

数据 + 模型 + 系统 + 应用 + 拓展

的完整路径设计。

学习目标¶

通过本教材，学生将能够：

  • 构建完整AI系统

  • 理解跨语言与跨模态问题

  • 参与真实数据构建

技术环境¶
